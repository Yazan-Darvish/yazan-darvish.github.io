# Портфолио Yazan Darvish

Статический сайт. Ни сервера, ни базы: в репозитории лежит готовый HTML,
его публикует GitHub Pages. Три языка: английский (по умолчанию), русский,
румынский.

**Стек:** HTML · CSS · ванильный JavaScript. Никаких зависимостей и сборщиков.

## Запуск

Любой статический сервер из папки `docs`:

```bash
python3 -m http.server 4174 --directory docs
```

Панель предпросмотра поднимает то же самое (`.claude/launch.json`, профиль
`site`).

Сайт открывается и **двойным щелчком по файлу**, без сервера: достаточно
открыть любой `docs/<lang>/<раздел>/index.html`. Ссылки между страницами ведут
на папку («../ru/work/»), а `file://` сам `index.html` для папки не
подставляет — поэтому `main.js` при `location.protocol === "file:"` дописывает
`index.html` ко всем внутренним ссылкам, заканчивающимся слэшем. На сервере
это правило не срабатывает, и адреса остаются чистыми. Такой же кусок есть
во встроенном скрипте `docs/index.html`.

Проверить, как сайт поведёт себя на GitHub Pages, можно так — разложить
`docs` в подпапку и открыть оттуда:

```bash
mkdir -p /tmp/pages/Profile && cp -R docs/. /tmp/pages/Profile/
cd /tmp/pages && python3 -m http.server 4180
# открыть http://localhost:4180/Profile/ru/skills/
```

## Как устроено

```
docs/
  index.html          переадресация с / на /en/
  en/  ru/  ro/       по папке на язык, внутри index.html каждой страницы
  static/css/style.css   единственный файл стилей
  static/js/main.js      тема, меню, фильтр проектов, форма, запуск игры
  static/js/game.js      мини-игра
  static/img/  static/cv/  media/
```

Страницы: `/<lang>/` · `/<lang>/work/` · `/<lang>/skills/` · `/<lang>/about/` ·
`/<lang>/contact/` · `/<lang>/project/<slug>/`

Язык — первым сегментом адреса, не параметром запроса: иначе статику не
разложить по файлам.

**Все пути относительные**, с пересчётом глубины: страницы языков лежат на
один уровень вниз (`../`), страницы разделов — на два (`../../`), страницы
проектов — на три (`../../../`). Это сделано ради GitHub Pages: репозиторий
называется `Profile`, поэтому сайт отдаётся не с корня домена, а с
`https://yazan-darvish.github.io/Profile/`, и абсолютные пути вида
`/static/css/style.css` вели бы мимо папки. Сайт работает и в корне, и
в подпапке — при правке ссылок это надо сохранять.

## Правка контента

Шаблонов больше нет: текст правится прямо в HTML. Одна и та же страница лежит
в трёх файлах — `docs/en/...`, `docs/ru/...`, `docs/ro/...`. Правка шапки,
подвала или меню нужна в каждом из 18 файлов.

Перед правкой стоит свериться, где текст повторяется:

```bash
grep -rl "нужная фраза" docs
```

## Страница навыков

Один список блоков (`.stack` / `.stack__item`), иерархия по важности.
Во главе блока — технология и строка, зачем она нужна: это читает человек без
технического опыта. Внутри пилюли с тем, что к ней относится: это читает
инженер, который ищет конкретное слово.

Тринадцать блоков, сетка в четыре колонки. Сначала четыре языка
программирования — PHP, Python, JavaScript, Dart, — они занимают ровно первый
ряд. Дальше области: архитектура, базы и поиск, инфраструктура, платёжное
железо, обмен данными, внешние сервисы, аналитика и отчёты, разговорные языки.
Области названы не языком потому, что Kafka и Elasticsearch не принадлежат
ни одному из них.

Последний блок — «Отрасли» — растянут на всю ширину (`.stack__item--wide`):
двадцать две пилюли в одну колонку не помещаются. Двенадцать блоков над ним
дают ровно три ряда по четыре.

Колонки ужимаются по ширине окна: 4 → 3 (1100px) → 2 (840px) → 1 (560px).

## Мини-игры по скиллам

`docs/static/js/skillgames.js` — своя игра на каждый скилл. Клик по пилюле
с `data-game="<id>"` открывает окно с игрой.

Правило жанра: **внутри игры не должно быть ни одного термина**. Сюжет
бытовой и понятный ребёнку, название технологии появляется только в финальной
плашке — «Это Laravel, и вот зачем он нужен».

Файлы разложены по доменам — один блок навыков, один файл:

```
docs/static/js/skills/
  core.js            оболочка: окно, реестр, помощники, запуск
  php.js  python.js  javascript.js  dart.js
  architecture.js  data.js  infrastructure.js  hardware.js
  exchange.js  services.js  analytics.js  languages.js  industries.js
```

Домен владеет и механикой, и своими текстами на трёх языках — они лежат
рядом в одном вызове `add()`. Ядро отдаёт наружу только `window.SkillGames`
с `add`, `t`, `ui`, `row`, `lead`, `count`, `on`, `later`; больше ничего
не торчит.

**Порядок подключения важен:** `core.js` идёт первым, домены после него,
все без `defer` и `async` — иначе домен обратится к `SkillGames` раньше,
чем тот появится, а `init()` не увидит игр.

Чтобы добавить игру:

1. открыть файл своего домена (или завести новый и подключить его в трёх
   `skills/index.html` после остальных);
2. написать `add("<id>", механика, тексты)` — механика получает `(area, api)`,
   рисует в `area` и зовёт `api.finish()` в конце; в текстах обязательны
   ключи `title`, `task`, `done` для `en`, `ru`, `ro`;
3. повесить `data-game="<id>"` на пилюлю в `docs/{en,ru,ro}/skills/index.html`.

**Осторожно с именами атрибутов.** Оболочка ловит клики по `data-close`
и `data-again` на всём окне, поэтому внутри игры эти два имени занимать
нельзя — кнопка игры перезапустит её вместо своего действия.

Стили окна — блок `.sg` в `style.css`. Пилюля с игрой помечается пунктирной
рамкой (`.has-game`), чтобы было видно, что она кликабельна.

Сделано — блок PHP целиком, семь игр: `laravel` (кухня: собери бургер
в пустой комнате и в готовой кухне), `symfony` (возьми из ящика ровно четыре
детали), `yii2` (три анкеты руками, остальные штампуются), `codeigniter`
(мост держит 3 кг, донеси письмо), `opencart` (магазин построен — завези
товар на полки), `bitrix` (соедини склад, бухгалтерию и магазин),
`wordpress` (собери страницу мышкой).

Блок Python — шесть игр: `openai` (спроси у соседа, словаря и всезнайки),
`rag` (ответ по памяти — догадка, ответ по твоей папке — точный), `vector`
(поиск по буквам даёт кружево, по смыслу — чашку), `llmprod` (ночная смена:
поток вопросов ускоряется), `aiassist` (покупатель в 02:15 — дать продавцу
поспать или ответить), `aisearch` («что-нибудь тёплое» обычный поиск
не находит).

Механики нарочно не повторяются: последовательность, выбор из множества,
автоматизация повтора, бюджет веса, заполнение слотов, соединение пар,
сборка на холсте, сравнение источников, поиск в документах, два режима
поиска, поток на таймере, диалог с ветвлением.

Игре с таймером отложенные шаги ставятся через `later()`, а не `setTimeout`:
`stopTimers()` гасит их при закрытии окна, иначе закрытая игра дорисовывает
себя в чужое.

Блок JavaScript — шесть игр: `htmlcss` (на голую страницу надеваются
шрифт, цвет, отступы), `vue` (сумма отстаёт, пока не перезагрузишь, потом
живая), `react` (двенадцать карточек: править каждую или править кирпич),
`nodejs` (разложить дела по залу и кулисам), `electron` (страница в браузере
и она же в окне программы), `exe` (оборвать интернет — браузер белеет,
касса работает).

Блок Dart — пять игр: `flutter` (родная кнопка на iPhone и Android разная,
своя — одинаковая), `appstore` (три замечания проверяющего, пока не снимешь —
не пропустит), `googleplay` (ползунок выката: 100% — ошибка у всех сразу),
`macos` (мак не открывает неподписанное), `dartexe` (из одной папки
собираются .exe, .app и приложение).

Внимание: подпись «десктоп (.exe)» встречается на странице **дважды** —
в блоке JavaScript (игра `exe`, про обрыв интернета) и в блоке Dart
(игра `dartexe`, про сборку под три платформы). При подключении по тексту
пилюли это надо учитывать: первое вхождение — JavaScript, второе — Dart.

Блок «Архитектура» — шесть игр: `ddd` (переименовать Entity#42 в «заказ»,
чтобы кладовщик понял), `micro` (сломать поиск по фото в башне и в посёлке),
`solid` (крутнуть винт: отваливается корзина, после разделения — только
кнопка), `oop` (одна форма, четыре печенья с разной начинкой), `phpunit`
(три правки вслепую — виноватой не найти; с проверками видно сразу),
`psr` (пять почерков в одной тетради против общего формата).

Kafka из «Архитектуры» убрана: блок теперь только про подходы, а Kafka
осталась в «Инфраструктуре», где ей и место. Дублей подписей на странице
больше нет, кроме «десктоп (.exe)».

Блок «Инфраструктура» — девять игр: `docker` (у коллеги не запускается —
три несовпадения), `kube` (домик падает ночью, смотритель поднимает сам),
`kafka` (лента: обзвон теряет двоих, ленту читают все трое), `rabbit`
(очередь: задание достаётся одному, добавил рук — разобрали быстрее),
`cicd` (выложить без проверок — ошибку найдут покупатели), `s3` (диск
забивается фотографиями), `ses` (со своего сервера четыре письма в спам),
`sentry` (покупатель ушёл молча или ошибка сама пришла с деталями),
`bash` (шаблон `*.jpg` ловит пять файлов из восьми).

Kafka и RabbitMQ нарочно сделаны разными механиками: лента, с которой
читают многие и событие остаётся, против очереди, где задание забирает
ровно один и оно исчезает. Это и есть разница между ними.

Блок «Базы и поиск» — шесть игр: `sql` (добавляешь условия, полка отдаёт
2 товара из 6), `postgres` (свет гаснет посреди перевода: по шагам деньги
пропали, «всё или ничего» — откатилось), `mysql` (сто читателей и один
продавец в одну книгу, потом копия для чтения), `redis` (один и тот же
вопрос: бегать в подвал или записать на листок), `elastic` (по названиям
ноль, по словам внутри — две книги), `algolia` (живая строка: печатаешь
«ко» — подсказка появляется сразу).

PostgreSQL и MySQL разведены нарочно: первый про целостность (транзакция),
второй про нагрузку на чтение (копии). Elasticsearch и Algolia тоже:
первый ищет слова внутри документов, второй подсказывает на лету.

Блок «Платёжное железо» — четыре игры: `serialport` (не та скорость — из
провода лезет каша), `arcus` (нажал второй раз — списано дважды; отменил —
деньги повисли; дождался — одобрено), `cashcode` (мятую выплюнуло,
подозрительную не взяло, сдачу отсчитало), `datecs` (стереть чек нельзя,
ошибку закрывают чеком возврата).

Блок «Обмен данными» — пять игр: `restapi` (четыре просьбы в окошко, две
выдать, двум отказать), `swagger` (без таблички проситель гадает, с ней
просит верно с первого раза), `erp` (сопоставить чужие ARTNR/BEZ/MENGE
со своими артикул/название/количество), `csvxml` (одна куртка в двух
обёртках, найди цену в каждой), `directdb` (партнёр переименовал полку,
и магазин лёг).

`restapi` и `directdb` нарочно перекликаются: первая про окошко, вторая
про ключ от чужого склада — и вторая заканчивается переходом на первое.

Блок «Внешние сервисы» — восемь игр: `twilio` (код из SMS доказывает, что
номер твой), `onesignal` (уведомление блокируется, пока человек не разрешил),
`sendgrid` (1000 отправлено → 962 дошло, 318 открыли, 47 нажали), `resend`
(пока домен не подтверждён, письмо уходит только себе), `sailplay` (баллы
копятся три покупки и закрывают часть четвёртой), `uds` (карту забыл — назвал
номер, скидка осталась), `gmaps` (вход через Google и адрес пальцем по карте),
`trello` (обращения раскладываются по колонкам сами).

Четыре игры про сообщения нарочно разведены: подтверждение номера,
разрешение получателя, статистика рассылки, подтверждение домена отправителя.

Блок «Аналитика и отчёты» — три игры: `ga4` (воронка: 288 уходят на одной
странице оплаты), `googleads` (щит вслепую против объявления с 71 заказом),
`reports` (та же неделя в трёх разрезах с итогом).

Блок «Языки» — пять игр: `lang_ru` (планёрка на полной скорости),
`lang_ro` (письмо налоговой: ждать перевода три дня или прочитать самому),
`lang_en` (ответ на Stack Overflow есть только по-английски),
`lang_ar` (арабские вывески — и честная граница базового уровня),
`lang_uk` (ложные друзья: «неділя» — не неделя, а воскресенье).

Игры про языки не хвалят уровень, а показывают его границу: в арабском
и украинском прямо сказано, где знания заканчиваются.

Блок «Отрасли» — одна игра `industries` на все 22 пилюли: семь документов
из разных дел (бронь, полис, объявление, накладная, столик, счёт SaaS,
запись в сервис), надо сказать, откуда каждый. Отдельная игра на каждую
отрасль выродилась бы в одно и то же «угадай магазин», а опереться там
не на что: проектов по большинству этих отраслей нет.

**Готово: 92 пилюли из 92, 71 уникальная игра** (22 отрасли делят одну).

Все файлы вместе — 340 КБ (91 КБ в gzip) и грузятся только на странице
навыков. Разбивка по доменам вес не уменьшила: она про порядок в коде.
Чтобы уменьшить вес, пришлось бы резать по второй оси — по языкам, вынося
тексты из доменов в отдельные файлы `text.<lang>.js`. Тогда посетитель тянул
бы примерно втрое меньше, но тексты перестали бы лежать рядом со своей
механикой.

## Метка версии ассетов

В каждой странице стоит `static/css/style.css?v=<число>`. Раньше её проставлял
Django по времени правки файла — теперь этого никто не делает, и **после правки
CSS или JS метку надо обновить руками во всех 18 файлах**, иначе у посетителей
останется старый кэш:

```bash
python3 - <<'EOF'
import pathlib, re
assets = list(pathlib.Path("docs/static/css").glob("*")) + list(pathlib.Path("docs/static/js").glob("*"))
v = int(max(a.stat().st_mtime for a in assets))
for p in pathlib.Path("docs").rglob("*.html"):
    p.write_text(re.sub(r'(static/(?:css|js)/[\w.-]+)\?v=\d+', rf'\1?v={v}', p.read_text()))
print("метка:", v)
EOF
```

## Публикация

```bash
git add docs && git commit -m "Правка сайта" && git push
```

`.github/workflows/pages.yml` ловит push в `main` с изменениями в `docs/**`
и раскатывает папку на GitHub Pages.

## Что осталось нерешённым

- **Форма обратной связи не работает.** Вёрстка на месте, но принимать POST
  некому — раньше это делал Django. Нужен внешний приёмник (Formspree и
  подобные) либо замена формы на ссылки почта/Telegram.
- **Поиск.** Оверлей по Cmd+K обращается в Algolia через fetch. Без ключей
  строка поиска просто не отображается.
- **Мёртвые домены.** `unde.md` и `crawless.com` не резолвятся, но ссылки на
  них стоят в проектах и в опыте работы.
- **Описания пяти проектов** (man.md, cort.md, petclub.md, greenshop.md,
  veloxi.md) написаны по контексту резюме, а не со слов владельца.
- **`backup.json`** — дамп удалённой базы. Внутри хэш пароля админа и три
  письма посетителей, поэтому он в `.gitignore`. Данные там устарели.

## Стиль работы

**С владельцем проекта общаться только по-русски.** Все ответы, пояснения и
вопросы — на русском языке, независимо от того, на каком языке написан код,
задача или сообщение.

Комментарии в коде — по-русски и объясняют «зачем», а не «что». Интерфейс
сайта — на трёх языках. Никаких лишних зависимостей: поиск ходит в Algolia
через fetch без библиотек, игра и голосовой ввод — на ванильном JS.
