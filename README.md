# Портфолио Yazan Darvish

Статический сайт-портфолио на трёх языках: английском, русском и румынском.
Готовый HTML лежит в папке `docs/`, оттуда его публикует GitHub Pages.

Ни базы, ни сервера, ни зависимостей: HTML, CSS и ванильный JavaScript.

## Посмотреть локально

Нужен любой статический сервер — открывать файлы двойным щелчком нельзя,
пути к стилям абсолютные.

```bash
python3 -m http.server 4174 --directory docs
```

Сайт откроется на http://localhost:4174

## Что внутри

```
docs/
  index.html             переадресация с / на /en/
  en/ ru/ ro/            по папке на язык
    index.html           главная
    work/                проекты
    skills/              навыки
    about/               обо мне
    contact/             контакты
    project/<slug>/      страница кейса
  static/css/style.css   стили
  static/js/main.js      тема, меню, фильтры, форма, страница навыков
  static/js/game.js      мини-игра (запускается кликом по заголовку главной)
  static/cv/             резюме в PDF на трёх языках
  static/img/  media/    изображения
```

Всего 18 страниц: 6 на каждый язык.

## Страница навыков

Тринадцать блоков. Во главе каждого — технология крупно и строка, зачем она
нужна: это понятно и тому, кто не разбирается. Внутри — пилюли с тем, что
к ней относится: Laravel и Symfony внутри PHP, Vue и React внутри JavaScript,
Flutter внутри Dart.

Первый ряд — четыре языка программирования: PHP · Python · JavaScript · Dart.
Дальше области: архитектура · базы и поиск · инфраструктура · платёжное
железо · обмен данными · внешние сервисы · аналитика и отчёты · разговорные
языки. Замыкают отрасли — во всю ширину. На широком экране четыре колонки,
на узком сетка схлопывается.

## Мини-игры

У каждого навыка на странице своя мини-игра: клик по пилюле открывает окно,
где бытовым сюжетом показано, зачем эта технология нужна. Терминов внутри игры
нет — название всплывает только в конце: «это Laravel, и вот зачем он».

92 пилюли, 71 игра (все 22 отрасли делят одну общую). Код — `skillgames.js`,
порядок добавления новой игры описан в `CLAUDE.md`.

После правки `style.css` или `main.js` нужно обновить метку версии `?v=`
во всех 18 страницах — иначе у посетителей останется старый кэш. Команда
есть в `CLAUDE.md`.

## Правка

Текст правится прямо в HTML. Одна страница — три файла, по одному на язык.
Общие части (шапка, меню, подвал) повторяются в каждом из 18 файлов, так что
перед правкой стоит найти все вхождения:

```bash
grep -rl "нужная фраза" docs
```

## Публикация

```bash
git add docs && git commit -m "Правка сайта" && git push
```

Workflow `.github/workflows/pages.yml` реагирует на push в `main` с
изменениями в `docs/**` и раскатывает папку на GitHub Pages.

## Известные ограничения

- **Форма обратной связи не отправляет.** Вёрстка есть, но принимать данные
  некому: нужен внешний сервис приёма форм либо замена на ссылки почта/Telegram.
- **Поиск** работает через Algolia и требует ключей. Без них строка поиска
  не показывается.
